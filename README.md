# Homework TUI

Organizador de tareas y materiales universitarios para la terminal, con interfaz en español y tema Gruvbox.

La versión disponible está en [`go/`](go/README.md). Detecta materias y archivos desde una carpeta local; las tareas se guardan fuera del repositorio, en el directorio de datos del usuario. La versión Python está pendiente.

El diseño se basa en [Gruvbox — TUI Design System](https://github.com/cola-runner/awesome-tui-design/blob/master/designs/gruvbox/DESIGN.md) de awesome-tui-design.
